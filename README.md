# Gihan Shevon Perera — Portfolio

A self-contained portfolio website for GitHub and Vercel.

## Deploy

1. Extract this ZIP.
2. Create a new GitHub repository or update your existing portfolio repository.
3. Upload `index.html`, `vercel.json`, `README.md`, and `.gitignore` to the **repository root**.
4. In Vercel, import the repository and deploy as a static site (no build command needed).

All images, styles and scripts are embedded in `index.html` — no `assets` folder is necessary.
