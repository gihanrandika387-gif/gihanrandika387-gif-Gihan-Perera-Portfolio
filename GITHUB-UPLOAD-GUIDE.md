# Upload this complete portfolio to GitHub

This archive contains the complete updated portfolio: `index.html`, all corporate design images under `assets/print-corporate/`, and Vercel configuration.

1. Download and extract the ZIP file.
2. Open your portfolio repository on GitHub.
3. Select **Add file > Upload files**. Drag all extracted files and the `assets` folder into GitHub, keeping the folder structure intact.
4. Commit the changes to your main branch.
5. If the repository is connected to Vercel, let it deploy the new commit. Otherwise, import the repository in Vercel.

**Important:** Do not upload the ZIP as a single file to the repository. Extract it first. `index.html` must remain at the repository root, and the `assets` folder must be uploaded with it so every mockup image loads.

The added corporate-design images are illustrative mockups; you can replace them with your real portfolio project images later.
