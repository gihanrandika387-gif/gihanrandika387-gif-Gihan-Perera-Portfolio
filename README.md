# Gihan Shevon Perera — Portfolio

A responsive personal portfolio featuring Pinnacle Promotions, Avianora, and direct contact links.

## Easy GitHub → Vercel publishing

This version is **self-contained**: all photos, logos, CSS, JavaScript, and the favicon are embedded inside `index.html`. You do **not** need an `assets` folder or a build step. Google Fonts are optional external font requests; the page also includes fallback fonts.

1. Create a new **public** repository on GitHub, for example `gihan-shevon-portfolio`.
2. Upload `index.html`, `README.md`, and `vercel.json` to the **root** of the repository (do not upload the ZIP itself).
3. Commit your changes.
4. Visit [Vercel](https://vercel.com/new), import the GitHub repository, select **Other** if asked for a framework, and deploy. No build command is needed.
5. Copy the **production** domain under Vercel → Settings → Domains and share it with clients or LinkedIn.

To preview locally, double-click `index.html` or run `python3 -m http.server 8000` in this directory.
