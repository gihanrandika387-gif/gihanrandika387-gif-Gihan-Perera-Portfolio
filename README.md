## GitHub: replace your current website

1. Open your **existing portfolio repository** on GitHub, in the root of the default/main branch.
2. Click **Add file → Upload files**.
3. Extract `Gihan_Perera_FULL_GitHub_Upload.zip` on your computer.
4. **Open the extracted folder.** Select `index.html`, `README.md`, and `vercel.json` **inside the folder**, then drag those three files into GitHub. **Do not drag the parent folder or the ZIP file.**
5. GitHub should display `/index.html`, `/README.md`, and `/vercel.json` — with no extra directory prefix. Commit directly to the main branch. Allow overwriting your previous versions.
6. Import this GitHub repository into Vercel, or trigger a redeploy of the existing Vercel project. Use `Other` / static site preset, root directory `./`, and no build command. Vercel serves root `index.html`.
